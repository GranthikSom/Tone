🎵 TONE

A lightweight and modern offline music player built with Flutter.

TONE focuses on delivering a clean, fast, and distraction-free listening experience. No accounts, no subscriptions, and no internet connection required—just your music.

Tech Stack

* Flutter
* Dart
* just_audio
* on_audio_query
* audio_service

Installation

git clone https://github.com/yourusername/tone.git
cd tone
flutter pub get
flutter run

Vision

TONE was built with a simple goal: create a beautiful and reliable music player that puts the user’s local music library first.
